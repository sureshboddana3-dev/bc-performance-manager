# BC Performance Manager (phone copy)

Static web app. No business data is stored in this repository. All data stays in the browser on the device that uses it (localStorage).

- Open `index.html` (or the Pages URL) in Chrome and use Add to Home screen.
- To move data from another copy: export a backup there ("Export backup"), then open `restore.html` here and choose that file.
- Export a backup regularly. Clearing browser data deletes the data on the device.
- Never commit backups, reports or contact lists to this repository.
